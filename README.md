# Madik Studio — HTML-версия

Полностью статический сайт без Astro, npm и обязательной сборки.

## Что внутри

- `index.html` — главная.
- `projects.html` — список проектов.
- `project.html?id=...` — универсальная страница проекта.
- `posts.html` и `post.html?id=...` — публикации.
- `about.html`, `contacts.html`, `404.html`.
- `data/projects.json` — проекты.
- `data/posts.json` — публикации.
- `data/site.json` — тексты и контакты.
- `.pages.yml` — настройка Pages CMS.
- `images/uploads/` — фотографии, загружаемые через CMS.

## Публикация на GitHub Pages

1. Распакуйте архив.
2. Загрузите **содержимое** папки в корень репозитория `MadikStudio/MadikStudio`.
3. Откройте `Settings → Pages`.
4. В разделе `Build and deployment` выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/(root)`
5. Сохраните настройки.

Адрес сайта:

`https://madikstudio.github.io/MadikStudio/`

`index.html` уже находится в корне. GitHub Actions и команда сборки не нужны.

## Pages CMS

1. Откройте `https://app.pagescms.org`.
2. Войдите через GitHub-аккаунт `MadikStudio`.
3. Подключите репозиторий `MadikStudio/MadikStudio`.
4. Используйте разделы:
   - «Настройки сайта»
   - «Проекты»
   - «Публикации»

После сохранения Pages CMS изменяет JSON-файлы и загружает изображения в `images/uploads/`. GitHub Pages обновляет статический сайт после изменения ветки `main`.

## Добавление проекта

В Pages CMS откройте «Проекты», добавьте новый элемент массива и заполните:

- `slug` — уникальный адрес латиницей, например `house-in-moscow`;
- название, категорию, год, локацию;
- обложку и галерею;
- краткое и полное описание;
- `published` — включить для публикации;
- `featured` — включить для главной страницы.

Адрес проекта формируется автоматически:

`project.html?id=house-in-moscow`

## Локальный просмотр

Поскольку контент загружается из JSON, лучше открывать сайт через простой локальный сервер:

```bash
python -m http.server 8000
```

Затем открыть:

`http://localhost:8000/`

При обычном открытии `index.html` двойным нажатием отображаются встроенные демонстрационные проекты, но изменения JSON могут не подхватиться из-за ограничений браузера для локальных файлов.

## Видео позже
